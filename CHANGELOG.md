# Changelog

All notable changes to `indigenous_languages_peru.csv` and `indigenous_languages_peru.xlsx` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-19

### Added
- Initial release of `indigenous_languages_peru.csv` and `indigenous_languages_peru.xlsx` (`48` records and `6` columns).
- Coverage of `48` indigenous or native languages of Peru (`44` Amazonian and `4` Andean across `18` linguistic families) compiled from official sources, preserving edge cases such as repeated ISO codes (`inp`, `jqr`) and the single-speaker record for *Taushiro* (`PE_41`, ISO `trr`, `NA` in `peoples_speaking_language`).
- UTF-8 encoding validation and import verification in R and Python, along with `README.md` and `CITATION.cff`.
